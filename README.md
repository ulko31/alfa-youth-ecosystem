# Alfa Youth Ecosystem

Продуктовый кейс по созданию молодёжной экосистемы для Альфа-Банка.

Основная идея проекта — превратить банковское приложение из инструмента для совершения операций в персональную digital-среду, которая помогает молодому пользователю управлять финансами, учиться принимать финансовые решения, взаимодействовать с друзьями и участвовать в экосистеме банка.

Центральный элемент продукта — персонализированный AI-аватар, который объединяет функции финансового помощника, наставника, игрового персонажа и цифрового отражения пользователя.

## Задача

Разработать продуктовую концепцию, которая позволит Альфа-Банку:

- привлечь молодую аудиторию;
- повысить вовлечённость пользователей;
- увеличить удержание;
- сформировать долгосрочную лояльность;
- увеличить использование банковских продуктов;
- развивать финансовую грамотность пользователей;
- укрепить позиционирование банка как инновационного бренда для молодёжи.

## Целевая аудитория

В рамках проекта были выделены три основных сегмента:

### Школьники

Особенности:

- финансово зависят от родителей;
- активно используют социальные сети и мобильные приложения;
- имеют небольшой опыт управления деньгами;
- заинтересованы в геймификации и интерактивном формате.

Основные потребности:

- финансовая грамотность;
- понятные банковские продукты;
- обучение управлению деньгами;
- ощущение самостоятельности;
- интересный и игровой формат взаимодействия.

### Студенты

Особенности:

- начинают самостоятельно управлять финансами;
- стремятся к финансовой независимости;
- активно используют банковские сервисы;
- интересуются образованием, карьерой и развитием.

Основные потребности:

- планирование бюджета;
- управление расходами;
- финансовая грамотность;
- накопления;
- персональные рекомендации;
- помощь в принятии финансовых решений.

### Самозанятые

Особенности:

- имеют нерегулярный доход;
- самостоятельно управляют финансами;
- сталкиваются с налогами и бизнес-процессами;
- ценят скорость и удобство digital-сервисов.

Основные потребности:

- автоматизация учёта доходов и расходов;
- планирование;
- финансовые рекомендации;
- обучение налогам и финансам;
- помощь в принятии решений.

## AI-аватар

Главный элемент продукта — виртуальный персонаж пользователя.

Он выступает одновременно как:

- финансовый помощник;
- наставник;
- игровой персонаж;
- визуальное отражение финансового состояния пользователя.

Внешний вид аватара можно персонализировать.

Пользователь получает виртуальную валюту и может использовать её для покупки:

- одежды;
- аксессуаров;
- скинов;
- кастомизации персонажа;
- визуальных элементов.

## Финансовый AI-наставник

AI-ассистент анализирует:

- доходы;
- расходы;
- категории трат;
- финансовые цели;
- историю операций.

На основе этого он может:

- помогать планировать бюджет;
- выявлять регулярные траты;
- прогнозировать будущие расходы;
- помогать создавать накопительные цели;
- предлагать способы оптимизации бюджета;
- рекомендовать финансовые продукты;
- объяснять последствия финансовых решений.

Пример сценария:

```text
Пользователь:
Хочу накопить на новый телефон.

AI-наставник:
Анализирует текущие расходы,
показывает основные категории затрат,
предлагает варианты экономии
и формирует план достижения цели.
```

## Экономические симуляции

Одной из центральных механик продукта стали интерактивные финансовые сценарии.

AI генерирует ситуации в зависимости от:

- возраста;
- сегмента пользователя;
- финансового поведения;
- интересов;
- уровня знаний.

### Для школьника

Пример:

```text
Тебе не хватает денег на покупку телефона.

Что выбрать?

- накопительный счёт;
- срочный вклад;
- инвестиции;
- ставки на спорт.
```

После выбора пользователь получает объяснение последствий решения.

### Для студента

Пример:

```text
Нужно оплатить обучение,
но денег недостаточно.

Что делать?

- кредит;
- микрозайм;
- кредитная карта;
- накопления.
```

AI объясняет плюсы и риски каждого варианта.

### Для самозанятого

Пример:

```text
Нужно купить оборудование для работы.

Варианты:

- кредит;
- рассрочка;
- покупка б/у;
- кредитная карта.
```

Такие сценарии превращают финансовую грамотность из теории в практический интерактивный опыт.

В приложение интегрируется виртуальная карта реальной местности.

На карте отображаются:

- партнёры Альфа-Банка;
- cashback;
- акции;

## Геймификация

В продукт встроены задания.

Примеры:

- выполнить финансовую цель на месяц;
- пригласить друга;
- пройти урок по финансовой грамотности;
- выполнить задание у партнёра;
- ознакомиться с новым банковским продуктом;
- пройти опрос.

За задания пользователь получает внутреннюю валюту.

Такая механика позволяет одновременно:

- обучать пользователя;
- повышать вовлечённость;
- увеличивать частоту взаимодействия с приложением;
- знакомить пользователя с другими продуктами банка.

## Автоокругление платежей

Пользователь может включить автоматическое округление покупок.

Например:

```text
Покупка: 243 ₽
Округление: до 250 ₽
Разница: 7 ₽
```

Разница может:

- переводиться на накопительный счёт;
- конвертироваться во внутреннюю валюту.

## Внутренняя валюта

В рамках экосистемы пользователь получает виртуальную валюту — «Альфики».

Их можно использовать для:

- кастомизации персонажа;

- участия в механиках экосистемы.

Механика также связана с социальной ответственностью.

При покупке скинов часть средств направляется в выбранный пользователем благотворительный фонд.
